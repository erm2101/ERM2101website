# Ed's original site, exactly as it was

`original-2021/` is a byte copy of https://github.com/ssh2192/ssh2192.github.io
as of the last commit to it, 2021-11-29. Nothing here is published: Jekyll skips
directories beginning with an underscore.

Kept so the before/after can always be reconstructed, and so nothing depends on
the old GitHub account (`ssh2192`) staying reachable. `edmorrisonportraittemp.jpg`
is also still at the repo root, so any existing link to the old photo resolves.
